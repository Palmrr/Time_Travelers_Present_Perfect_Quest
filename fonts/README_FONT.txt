ฟอนต์ FkBurger (ผู้ออกแบบ: Kancha, https://www.f0nt.com/release/fkburger/)
- เกมถูกตั้งค่าให้ใช้ฟอนต์ FkBurger กับตัวอักษรทั้งหมด แต่ "ไม่ได้แนบไฟล์ฟอนต์มาให้" เพราะ:
  1) ไฟล์ฟรีบนเว็บเป็นเวอร์ชัน Demo สำหรับใช้ส่วนตัวเท่านั้น (เส้นบาง และอักษรไม่ครบบางตัว)
  2) เวอร์ชันเต็มราคา 100 บาท (องค์กร/โรงเรียน 500 บาท) ใช้เชิงพาณิชย์ได้
- วิธีใช้: ดาวน์โหลด/ซื้อฟอนต์แล้วนำไฟล์มาวางในโฟลเดอร์นี้ ตั้งชื่อ FkBurger.ttf (หรือ FkBurger.otf / FkBurger.woff2)
  เปิด index.html ใหม่ ฟอนต์จะเปลี่ยนทันที (หรือติดตั้งฟอนต์ในเครื่องก็ใช้ได้)
- ถ้าไม่มีไฟล์ฟอนต์ หรืออักษรบางตัวไม่มีในฟอนต์ เกมจะใช้ฟอนต์สำรอง (Leelawadee UI / Tahoma / sans-serif) อัตโนมัติ
- ถ้านำเกมขึ้นเว็บสาธารณะ ให้ตรวจสัญญาอนุญาตของฟอนต์ก่อน (ฟอนต์ Demo ห้ามใช้เชิงสาธารณะ/พาณิชย์)
